# Renova Desktop

**Status: planned, not started.**

A downloadable **JavaFX** app for customers whose code cannot leave their machines. It runs the
[Renova engine](../engine) in-process, with no server, and is packaged per operating system with
`jpackage` (bundled Java runtime, no install prerequisites).

Planned scope:
- Open a project folder, run the assessment, and browse findings by category with the automation rate.
- Review the plan, run the migration with progress per stage, and review each stage's diff.
- Configure the AI provider with the user's own key, stored in the Renova user config.
- Open the Markdown and JSON reports.
