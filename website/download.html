Before you migrate

What your machine needs

Renova itself needs nothing more than the installer. To build and test the migrated project it uses that project's own tools.

Java projects

Git, and Maven or Gradle

A JDK for the target is found on the machine or downloaded. Network access to Maven Central, or your own mirror.

.NET projects

The .NET SDK of the target

.NET 10 or 8, and network access to nuget.org or your own feed. Windows Forms and WPF build on Windows.

PHP projects

Composer and the target PHP

PHP 8.3, 8.4 or 8.5 beside whatever PHP is installed. Renova finds the usual install locations.

Optional. Docker, to run the original beside the migrated application and compare their answers. An Anthropic or OpenAI API key, for the steps that need AI.
Licence. Assessing projects is free and needs no licence. Migrating needs a licence file for the ecosystem; it is checked on your machine and nothing is sent anywhere. How licences work · Request one.
